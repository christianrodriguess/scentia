Os requisitos devem ser atualizados durante o semestre conforme a evolução do projeto.

| ID | Requisito | Prioridade | Etapa |

| ID | Requisito | Prioridade |
|---|---|---|
| RNF-01 | A aplicação deverá possuir interface responsiva. | Alta |

## 2.3 Evolução dos requisitos

Quando um requisito for alterado, removido ou incluído, registrar a mudança de forma coerente com a evolução do projeto e com os commits realizados no repositório.
