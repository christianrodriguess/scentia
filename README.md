# Sobre o projeto

O projeto será desenvolvido de forma incremental ao longo do semestre. Cada etapa deverá evoluir a mesma aplicação, incorporando os conteúdos trabalhados na disciplina.

O desenvolvimento deverá ser registrado no repositório por meio de commits coerentes com a evolução do projeto. Os commits serão considerados pela relevância, regularidade e coerência das alterações realizadas, e não apenas pela quantidade.
